

# Banking Products Dashboard

## Project Overview
Banking dashboard that displays multiple
banking products on a single screen.

## Technologies
- Java 21
- Spring Boot
- Spring Web
- HTML5
- JSON

## Features
1. Display banking products.
2. Savings account information.
3. Credit card information.
4. Loan information.
5. Wealth product information.
6. Search products by id
7. View product details.


## Backend API

GET /api/products/all
GET /api/products/{id}

## Data Storage
Hard-coded Java ArrayList.
No database required.

## Run Application

1. Import project into Eclipse or IntelliJ.
2. Run BankingDashboardApplication.java.
3. Open browser.
4. Visit http://localhost:8080/
